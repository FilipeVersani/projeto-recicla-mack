# ♻️ ReciclaMack — Lixo Eletrônico e Logística Reversa

## 📌 Sobre o Projeto

O **ReciclaMack** é um site desenvolvido com o objetivo de conscientizar e informar sobre o descarte correto de lixo eletrônico (e-lixo) e a importância da logística reversa. O projeto apresenta conteúdo educativo sobre os impactos ambientais do descarte inadequado de equipamentos eletrônicos e orienta os usuários sobre como e onde descartar seus resíduos de forma responsável.

🔗 **Acesse o site:** [https://filipeversani.github.io/projeto-recicla-mack/](https://filipeversani.github.io/projeto-recicla-mack/)
